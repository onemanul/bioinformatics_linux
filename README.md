# bioinformatics_linux
Homework assignments for the subject Linux. Bioinformatics, SPbU, 2026

## Домашняя работа 4

1. `1.sh` — анализ логов веб-сервера: извлекает IP и коды состояния (awk), заменяет ошибки 4xx на CLIENT_ERROR (sed), считает число запросов по каждому IP.
2. `2.sh` — обработка прайс-листа: считает стоимость товаров на складе по категориям (awk), убирает товары с нулевым остатком (sed), выводит товары дороже 100.
3. `3.sh` — отчёт по дискам: форматирует вывод `df -h` (awk), очищает и заменяет текст (sed), предупреждает о заполненности выше 80%.
4. `4.sh` — трансформация config.json в формат `ключ=значение` (sed), добавляет префикс CONF_ (awk) и экспортирует переменные окружения.
5. `5.sh` — анализ текста: приводит к нижнему регистру и убирает пунктуацию (sed), считает топ-5 частых слов (awk), запрашивает их определения через dictionary API.
6. `6.sh` — исправление "грязного" CSV: меняет разделитель и чинит разорванные строки (sed), проверяет число полей (awk), формирует предложения по каждой записи.
7. `7.sh` — создаёт структуру проекта `my_project` с поддиректориями и выводит список созданных директорий.
8. `8.sh` — создаёт 10 лог-файлов с нумерацией, выводит их содержимое и удаляет файлы с чётными номерами.
9. `9.sh` — переименовывает файлы `document*.txt` в `file*.txt` и перемещает их в отдельную директорию.
10. `10.sh` — создаёт резервные копии по дням (`day_1`...`day_7`) и собирает их в общую папку `all_backups`.
11. `11.sh` — сортирует файлы по расширениям в директории `images`, `documents`, `scripts`, `archives`.
