# bioinformatics_linux
Homework assignments for the subject Linux. Bioinformatics, SPbU, 2026

## Домашняя работа 3

1. `1.sh` — проверяет формат CSV/TSV-файла и корректность (одинаковое число столбцов в каждой строке).
2. `2.sh` — создаёт резервные копии всех `.txt` файлов в директории, добавляя дату к имени.
3. `3.sh` — находит 10 самых частых слов в текстовом файле.
4. `4.sh` — генерирует отчёт по директории: количество файлов по типам и общий размер.
5. `5.sh` — читает файл с оценками (ФИО, оценка, предмет) и выводит студентов с оценкой выше порога по каждому предмету.
6. `6.sh` — пропинговывает список хостов и выводит результаты.
7. `7.sh` — обратный отсчёт с анимацией из звёздочек.
