# bioinformatics_linux
Homework assignments for the subject Linux. Bioinformatics, SPbU, 2026

## Домашняя работа 2

1. `1.sh` — принимает флаг `-u`/`-l` и слово, выводит его в верхнем/нижнем регистре.
2. `2.sh` — меняет расширение файла (путь, текущее и желаемое расширение); поддерживает только txt, pdf, doc.
3. `3.sh` — проверяет, что передано ровно 3 аргумента, иначе ошибка.
4. `4.sh` — проверяет, что переданный файл является FASTA.
5. `5.sh` — создаёт мягкую ссылку на переданный файл в рабочей директории, если файл существует.
6. `6.sh` — принимает файл и название организма (human/mouse/rat/fly), выводит сообщение об обработке или ошибку для неизвестного организма/отсутствующего файла.
7. `7.sh` — для директории выводит список файлов, для файла — подробную информацию и число строк; ошибка, если путь не существует.
